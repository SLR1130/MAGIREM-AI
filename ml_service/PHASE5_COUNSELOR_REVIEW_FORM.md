# Phase 5 — Counselor Review and Adjudication Form

This form is for qualified guidance professionals reviewing **synthetic,
non-diagnostic examples**. It is not a psychological scale and must not be used to
diagnose a student. Do not paste real student messages into the evaluation files.

## Reviewer instructions

1. Read the operational definition and the full message context.
2. Label only an emotion clearly attributable to the student. A reported or
   hypothetical emotion belongs in the attribution fields, not automatically in
   the student's primary emotion.
3. Use `mixed` only when two or more emotions are simultaneously expressed with
   enough evidence. Use `uncertain` when evidence is ambiguous or insufficient.
4. Use `no_emotion` for an informational/neutral message without an emotional
   state. Use `attributed_other` when the emotion is clearly another person's.
5. Do not infer diagnosis, severity, risk, personality, or clinical meaning.
6. Record disagreements explicitly; do not silently force consensus.

## Allowed status and attribution values

| Status | Use when |
| --- | --- |
| `clear` | One student emotion is sufficiently supported. |
| `mixed` | At least two student emotions are simultaneously and explicitly expressed. |
| `uncertain` | Emotion is ambiguous, weakly evidenced, negated, or hypothetical. |
| `no_emotion` | No specific emotional state is expressed. |
| `attributed_other` | Emotion is clearly about another person, not the student. |

| Attribution | Use when |
| --- | --- |
| `student` | The message attributes the emotion to the student. |
| `other` | The message attributes it only to someone else. |
| `both` | The student and another person are both described. |
| `hypothetical` | The emotion is conditional or imagined rather than experienced. |
| `none` | No attributable emotion is present. |

## Adjudication notes

The adjudicator should document why one label was selected, whether the operational
definition was unclear, and whether the example should be rewritten. Any example
that could reveal a real person, sensitive event, or crisis content must be removed
from the evaluation set.
